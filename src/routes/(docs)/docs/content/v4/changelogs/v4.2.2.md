Release date: **November 19, 2026**

> [!IMPORTANT]
> Upgrade if you use hidden monitors. Before v4.2.2, an incident or maintenance that affected only hidden monitors was public on some pages. See [Events of hidden monitors](#hidden-only-events).

## Events of hidden monitors {#hidden-only-events}

A hidden monitor has `is_hidden = YES`. Before v4.2.2, Kener left hidden monitors out of an event's list of affected monitors. But an incident or maintenance that affected only hidden monitors still showed its title, description, and comments in these places:

- The events page at `/events/{month}-{year}`.
- The RSS feed at `/rss.xml`.
- The incident page `/incidents/{id}` and the maintenance page `/maintenances/{id}`.

Kener now shows an event in these places only when the event is global (`is_global = YES`) or affects a monitor that is not hidden. For any other event, the incident and maintenance pages return 404. A signed-in user whose role has `monitors.read` sees hidden monitors, so that user can still open the page of an event that affects only hidden monitors. See [Monitor Visibility](/docs/v4/monitors/visibility#where-each-rule-applies).

A non-global event that has no affected monitors now also stays off these lists and pages. An event loses its affected monitors when you delete them. Page lists and subscriber emails already left out these events. New incidents and maintenances are global by default.

What to do:

1. Upgrade to v4.2.2.
