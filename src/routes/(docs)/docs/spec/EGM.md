# spec

## Overview

This folder groups the API reference routes under `/docs/spec/`. It has no source files of its own. Each child folder serves the reference for one API version.

## Subdirectories & Boundaries

- [v4](./v4/EGM.md): The route `/docs/spec/v4` serves the interactive Scalar reference page, and its child `/docs/spec/v4/spec.json` serves the OpenAPI document for `/api/v4`.
